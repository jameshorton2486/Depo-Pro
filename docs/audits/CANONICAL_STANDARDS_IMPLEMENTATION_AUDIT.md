# Canonical Standards Implementation Audit

Date: 2026-06-26  
Branch: feature/stage3-workspace-core  
Authority: `CANONICAL_EDITORIAL_POLICY.md` + `DP-010_SENTENCE_BOUNDARY_ABBREVIATION_SPACING.md` + `CHANGELOG_dp012_qa_review.md` + `abbreviation_registry.json`

## Executive Summary
Most of the canonical display rules are live in the workspace path already: DP-010 spacing is substantially implemented through the CFE, Q/A splitting and objection handling are implemented in `qaFixer`, speaker inference and structural markers are implemented in `workspacePresentation`, and the deterministic garble map is active in `cfe.ts`. The largest remaining gaps are not core sentence spacing; they are export hygiene and higher-order deposition structure details: registry single-source discipline is only partial outside the CFE, inline garble flags are not stripped from final text exports, and the `(BY MR. ___)` re-entry rule is still not implemented. Current display-layer rules preserve audio sync because they run in `cfe.ts`, `qaFixer.ts`, and `workspacePresentation.ts` after canonical words are loaded and without mutating `transcript_words` or `transcript_utterances` [src/lib/format/cfe.ts:545-632] [src/lib/transcript/qaFixer.ts:139-151] [src/lib/transcript/workspacePresentation.ts:479-568].

## Section 5: Classification of Remaining Gaps

### Display-layer safe (can implement now)
- Complete the registry single-source cleanup by replacing hardcoded honorific regexes in `workspacePresentation.ts`, `colloquy.ts`, and `paragraphDisplayImprovements.ts` with a registry-backed helper. This is display-layer safe because those modules already transform rendered text only [src/lib/transcript/workspacePresentation.ts:111-127] [src/editor/stageS/colloquy.ts:1-15] [src/lib/transcript/paragraphDisplayImprovements.ts:8-23].
- Add the optional `likely "..."` clause to inline flags if the canonical standard still requires it. The additive flag path already exists in `buildInlineFlag` [src/lib/format/cfe.ts:512-513].
- Implement `(BY MR. ___)` re-entry markers and no-colon resumption handling in `workspacePresentation.ts` / `qaFixer.ts`. Current code only emits `BY MR. ___:` bylines, so adding the parenthetical re-entry marker would be a display-layer structural change without touching canonical words [src/lib/transcript/workspacePresentation.ts:95,403,521].
- Add a flag-stripping path for clean TXT/Word exports in `transcriptDownloads.ts` if final delivery should omit `[SCOPIST: FLAG]`. Today both raw and structured text exports preserve inline flags [src/lib/format/serialize.ts:3-7] [src/lib/transcript/workspacePresentation.ts:80-82] [src/lib/transcriptDownloads.ts:13-19].
- Expand geometry verification to explicitly pin QA label/text tab positions alongside the existing Tab3/Tab4 assertions. The geometry data already exists in `DEFAULT_GEOMETRY_PROFILE` [src/lib/format/geometryProfile.ts:11-17] [src/lib/buildEditorContent.test.ts:245-255].

### Canonical-layer unsafe (do not implement — would break sync)
- Any attempt to rewrite `word.text`, split canonical words, or pre-mutate `EditorDocument.words` so the transcript is “fixed before workspace load” would alter the token stream that backs word-level timestamps. The current architecture intentionally keeps formatting and structural corrections in CFE / `qaFixer` / `workspacePresentation` after the canonical document is loaded [src/lib/format/cfe.ts:545-632] [src/lib/transcript/qaFixer.ts:139-151] [src/lib/transcript/workspacePresentation.ts:479-568].
- Moving Q/A splitting into canonical utterance or word persistence would be unsafe because `qaFixer` currently preserves `sourceWordIds` and `sourceUtteranceIds` across split children precisely to avoid breaking audio binding [src/lib/transcript/qaFixer.ts:17-28,122-151] [src/lib/transcript/qaFixer.test.ts:58-71].

### Post-beta (schema required)
- Participant-directory / synthetic-speaker support remains post-beta because merged diarization clusters still require schema-level speaker modeling beyond the display-layer inference guard. The current display layer can protect reporter/videographer labels, but it cannot create new canonical participant rows or split Deepgram clusters without the later nullable-`deepgram_speaker` migration already audited elsewhere [src/lib/transcript/workspacePresentation.ts:304-347].

### Deferred by design
- Direct-address capitalization is intentionally deferred in the opposite direction: DP-012 explicitly rejected auto-capitalizing direct-address `doctor`, and commit `a35a4a4` removed that behavior [Canonical Standards Folder/CHANGELOG_dp012_qa_review.md:13,41-42] [git show a35a4a4].
- Spoken date ordinals are intentionally preserved rather than normalized because commit `e731ebf` removed the auto-apply behavior and the current regression suite locks that choice in [git show e731ebf] [src/lib/format/cfe.test.ts:253-263].
