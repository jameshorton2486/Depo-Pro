# Audit Index

This directory contains point-in-time engineering audits, validation results, gap
analyses, and implementation assessments. Audit documents are evidence, not governing
authority, unless a governing document explicitly adopts one.

## Collections

- `2026-07-20-git-governance/` - repository and branch-governance review
- `rc/` - release-candidate baselines and verification
- `stage-s/` - Stage S ownership, repair burden, and validation

Files at this directory top level cover cross-cutting application concerns. Use
specific, descriptive filenames and include a date when the subject is likely to be
audited repeatedly.

Completed implementation and remediation reports belong in
[the archive](../archive/reports/) rather than this evidence directory.

## Repository documentation

- [Root document disposition](ROOT_DOCUMENT_DISPOSITION_2026-08-05.md) records the reviewed status and final location of every formerly tracked root Markdown file.
