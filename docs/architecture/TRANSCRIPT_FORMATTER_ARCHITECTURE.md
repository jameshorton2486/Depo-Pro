# Depo-Pro Transcript Formatter Architecture

## Overview

The Depo-Pro formatter pipeline converts Deepgram transcription output into a legally formatted deposition transcript.

The system follows a strict transformation pipeline.

Deepgram JSON
      ↓
transcript_words
      ↓
Section Detector
      ↓
Paragraph Builder
      ↓
Post Processor
      ↓
transcript_paragraphs
      ↓
Paginator
      ↓
Quality Gate
      ↓
Inclusion Page Generator
      ↓
DOCX Assembler
      ↓
Export API

This architecture ensures:

• transcripts remain verbatim
• corrections are traceable
• formatting is court-compliant
• exports are certifiable

## Core Data Model

### transcript_words

This table stores the raw word-level transcript from Deepgram.

transcript_words
----------------
id
transcription_id
speaker
word
start_time
end_time
confidence
punctuated_word
created_at

Example:

speaker: 1
word: "Yes"
start_time: 12.43
end_time: 12.62
confidence: 0.97

This table is immutable.

Never modify Deepgram output.

### transcript_paragraphs

Generated by the formatter pipeline.

transcript_paragraphs
---------------------
id
transcription_id
paragraph_text
paragraph_type
speaker_label
word_start
word_end
page_number
line_number
created_at

Paragraph types:

QUESTION
ANSWER
EXAMINATION
COLLOQUY
STATEMENT

Example:

Q. Please state your name for the record.

## Section Detector

Identifies transcript structure.

Detects:

Q.
A.
BY MR.
BY MS.
COLLOQUY

Example:

Q. Where were you on the evening of March 4?

Detected as:

paragraph_type = QUESTION
speaker_label = "ATTORNEY"

## Paragraph Builder

Converts word stream into paragraphs.

Input:

transcript_words

Output:

transcript_paragraphs

Grouping logic:

• speaker change
• punctuation boundary
• section change

## Post-Processor

Normalizes transcript text.

Rules:

— → --
THE COURT REPORTER → THE REPORTER
“ ” → "
‘ ’ → '

Removes formatting inconsistencies.

## Paginator

Applies legal transcript page rules.

Texas format:

25 lines per page
line numbers
Courier New
12pt

Adds:

page_number
line_number

## Quality Gate

Prevents invalid transcripts from exporting.

Checks:

VERIFY tags unresolved
missing answers
invalid speaker labels
page overflow
duplicate lines
missing certification page
timestamp inconsistencies
paragraph errors
speaker mismatch
missing metadata
formatting violations

If errors exist:

EXPORT BLOCKED

## Inclusion Pages

Generates front matter.

Pages:

Appearance Page
Index Page
Certification Page

Data sources:

cases table
jobs table
profiles table

Certification page example:

CERTIFICATE OF REPORTER
STATE OF TEXAS

I, [REPORTER NAME], CSR No. [CSR#], certify that the
foregoing deposition was taken before me...

• mix transcript layers
• break pagination
• invent schemas
• violate legal formatting

With it, code generation becomes much more reliable.
