# Documentation Archive

This directory preserves completed or historical project records that remain useful
for traceability but are not current governing authority.

- [Architecture](architecture/) contains superseded architecture and governance drafts.
- [Audits](audits/) contains inactive audit and governance-model evidence.
- [Reports](reports/) contains completed implementation, migration, remediation, and
  verification reports.
- [Handoffs](handoffs/) contains dated session and project-transition records.
- [Status](status/) contains superseded milestones and completion snapshots.

Archived material may describe an earlier implementation state. Consult the
[documentation index](../README.md) and current architecture before relying on it.
